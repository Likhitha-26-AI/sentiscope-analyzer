# SentiScope - AI Sentiment Analyzer

An AI-powered sentiment analysis web application that classifies text as positive or negative using Hugging Face Transformers.

## Features
- Real-time sentiment analysis
- Clean, modern UI with gradient design
- Confidence score display
- Built with Streamlit and Hugging Face

## Installation

1. Clone the repository
```bash
git clone https://github.com/Likhitha-26-AI/sentiscope-analyzer.git
cd sentiscope-analyzer
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Run the application
```bash
streamlit run sentiment_app.py
```

- Python

- Hugging Face Transformers
